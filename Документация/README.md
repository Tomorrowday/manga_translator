📖 Manga Translator (AI-Powered Scanlation Studio)

Manga Translator — автономное гибридное десктопное приложение для полной
автоматизации процесса перевода и тайпсеттинга манги (сканлейта).
Приложение объединяет локальные нейросети на GPU (RTX 50-й серии) для детекции
баблов и распознавания текста, облачную LLM Google Gemini для контекстного
литературного перевода, алгоритмический движок очистки сканов (OpenCV
Inpainting) и интерактивную студию верстки с прямым запеканием (Baking Engine)
в 100% исходном качестве.

🏗 Архитектура системы

Проект построен по архитектуре BFF (Backend-For-Frontend):

  - Frontend (Next.js 15 / React 19): Интерактивная графическая среда
    переводчика и тайпсеттера: Drag&Drop баблов, визуальный подгон текста
    (WYSIWYG), переключение порядка реплик, привязка персонажей и холст
    рендеринга высокого разрешения.
  - Backend (FastAPI / Python): Модульный асинхронный сервер. Управляет
    локальными моделями на GPU, работает с базой данных SQLite и файловой
    системой напрямую через NVMe/SSD без сетевых накладных расходов.

[ Файлы на SSD (RAWs) ] ───► [ Local GPU (RTX 5070 Ti) ]
                                    │
                                    ├─ YOLOv8 (Детекция баблов + Manga Sort)
                                    ├─ MangaOCR (ViT + RoBERTa на CUDA)
                                    └─ OpenCV (Клин баблов в #FFFFFF)
                                            │
                                            ▼
[ Next.js 15 UI ] ◄─── [ FastAPI BFF ] ────► [ Google Gemini API ]
  (WYSIWYG Typeset,      (SQLite Cache,        (Контекстный перевод главы
   HTML5 Canvas Bake)     Chapter Pipeline)     с учётом персонажей)

⚡ Ключевые возможности

1.  Правильный порядок чтения манги (Manga Reading Order):

      - Баблы автоматически сортируются справа налево, сверху вниз сразу после
        YOLO-детекции с разбиением страницы на смысловые ярусы кадров.
      - В интерфейсе доступна ручная корректировка очерёдности реплик
        (order_index).

2.  Разметка персонажей (Speaker Tagging):

      - Возможность указать автора реплики (например: [Макима], [Дэндзи]).
      - Gemini автоматически адаптирует род глаголов, местоимения (он/она),
        уровень вежливости (кэйго) и характерную манеру речи персонажа.

3.  Пакетная обработка главы в 1 клик (Chapter Pipeline):

      - Вместо сотен сетевых запросов браузера бэкенд выполняет локальный OCR на
        видеокарте прямо с диска и отправляет ровно 1 запрос в Gemini на всю
        главу.
      - Полное отсутствие ошибок лимитов HTTP 429 Too Many Requests.
      - Модель переводит каждую фразу, зная развязку сцены и события предыдущих
        страниц.

4.  Интеллектуальный клин баблов (OpenCV Inpainting):

      - Локализует текст внутри бабла и заливает его кристально-белым цветом
        (#FFFFFF), не повреждая черные границы рамок и окружающий арт рисунка.
      - Автоматическое устранение желтизны бумаги и сканерного шума с
        сохранением результатов в папку clean/.

5.  Профессиональный тайпсеттинг и Canvas Baking:

      - Поддержка сканлейтерских шрифтов Windows (v_CCFaceFront, v_Augie,
        v_Blambot Casual и др.).
      - Автоматический расчет кегля под площадь бабла, белая обводка текста
        (Stroke), переносы слов без разрыва слогов.
      - Запекание финальных страниц в подпапку translated/ в 100% оригинальном
        разрешении исходника (без экранного сжатия).

🛠 Стек технологий

Бэкенд (Python 3.11+)

  - FastAPI / Uvicorn — асинхронный веб-сервер и REST API.
  - PyTorch (CUDA 12.8) — инференс локальных моделей с оптимизацией под
    архитектуру NVIDIA Blackwell.
  - Ultralytics YOLOv8 (yolo_manga.pt) — мгновенная детекция баблов на сканах.
  - MangaOCR (kha-white/manga-ocr-base) — оптическое распознавание вертикального
    и горизонтального японского текста с фуриганой.
  - Google Generative AI SDK — литературный перевод через Gemini
    (gemini-2.5-flash / gemini-3.5-flash-lite).
  - OpenCV (cv2) & NumPy — алгоритмическая бинаризация, маскирование и очистка
    сканов.
  - SQLite3 — локальная БД с внешними ключами и каскадным удалением.

Фронтенд (Node.js 24+)

  - Next.js 15+ (App Router, React 19) — каркас пользовательского интерфейса.
  - Tailwind CSS — утилитарная стилизация и темная тема студии.
  - Lucide-React — векторные иконки интерфейса.
  - HTML5 Canvas API — движок полноразмерного рендеринга и запекания графики.

🗄 Структура данных и хранение на диске

Иерархия файлов проекта

D:/Manga/Title_Name/
└── Chapter 01/
    ├── 01.jpg, 02.jpg ...           # Исходные «сырые» сканы (RAWs)
    ├── clean/                       # Очищенные сканы (создаются автоматически)
    │   ├── 01.png, 02.png ...
    └── translated/                  # Готовые страницы со впечатанным переводом (100% качество)
        ├── 01.png, 02.png ...

Схема базы данных (SQLite)

  - titles: id, name, folder_path, created_at
  - chapters: id, title_id, volume_number, chapter_number, folder_path
  - pages: id, chapter_id, page_number, file_path, clean_path, status (new |
    in_progress | done)
  - text_blocks: id, page_id, x, y, width, height, jap_text, rus_text, speaker,
    order_index, status
  - glossary: id, title_id, jap_word, rus_word, context

📡 Справочник REST API

| Метод      | Эндпоинт                           | Назначение                                                |
| :--------- | :--------------------------------- | :-------------------------------------------------------- |
| **POST**   | `/api/projects/scan`               | Сканировать локальную папку на диске и занести тайтл в БД |
| **GET**    | `/api/projects`                    | Получить список всех добавленных тайтлов                  |
| **GET**    | `/api/projects/{id}/tree`          | Получить дерево тайтла (Главы ➔ Страницы)                 |
| **DELETE** | `/api/projects/{id}`               | Удалить тайтл и его разметку из БД (файлы не удаляются)   |
| **GET**    | `/api/pages/{id}/image`            | Получить исходное изображение страницы                    |
| **GET**    | `/api/pages/{id}/clean-image`      | Получить очищенный скан страницы (или оригинал)           |
| **GET**    | `/api/pages/{id}/blocks`           | Загрузить координаты, тексты и спикеров страницы          |
| **POST**   | `/api/pages/{id}/blocks`           | Сохранить актуальное состояние блоков страницы (`Ctrl+S`) |
| **POST**   | `/api/pages/{id}/detect`           | Быстрый автодетект баблов прямо с SSD (YOLO + Manga Sort) |
| **POST**   | `/api/pages/{id}/clean`            | Запустить алгоритм OpenCV-очистки баблов страницы         |
| **POST**   | `/api/pages/{id}/save-translated`  | Сохранить готовую запечённую страницу в `translated/`     |
| **POST**   | `/api/pages/{id}/open-folder`      | Открыть папку `translated/` в проводнике Windows          |
| **POST**   | `/api/chapters/{id}/translate-all` | **Пакетный перевод всей главы за 1 запрос к Gemini**      |
| **POST**   | `/api/ocr`                         | Распознать японский текст на кропе (MangaOCR)             |
| **POST**   | `/api/translate`                   | Одиночный перевод фразы через Gemini                      |
| **POST**   | `/api/translate/batch`             | Пакетный перевод реплик одной страницы                    |

🚀 Установка и запуск

1. Системные требования

  - ОС: Windows 10/11 (64-bit).
  - GPU: NVIDIA с поддержкой CUDA (рекомендуется от 8GB VRAM).
  - Python: 3.11+.
  - Node.js: 20+ (рекомендуется Node.js 24).

2. Клонирование и настройка окружения

git clone https://github.com/your-repo/manga-translator.git
cd manga-translator

Создайте файл .env в корне проекта:

GEMINI_API_KEY=ваш_ключ_google_gemini_api

3. Настройка Бэкенда (Python)

python -m venv venv
venv\Scripts\activate

# Установка PyTorch с поддержкой CUDA 12.8
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128

# Установка остальных зависимостей
pip install fastapi uvicorn python-multipart opencv-python pillow ultralytics manga-ocr google-generativeai python-dotenv

Положите файл весов модели yolo_manga.pt в корень проекта.

4. Настройка Фронтенда (Next.js)

cd manga_ui
npm install

5. Запуск студии

Для запуска обоих серверов одновременно воспользуйтесь скриптом:

start_all.bat

Или запустите раздельно в двух терминалах:

  - Бэкенд: uvicorn main:app --reload --port 8000
  - Фронтенд: cd manga_ui && npm run dev

Интерфейс студии откроется по адресу: http://localhost:3000.

🔄 Стандартный рабочий процесс (Workflow)

1.  Откройте Explorer в левой панели и нажмите «+», чтобы указать папку с мангой
    на диске.
2.  Выберите главу и нужную страницу в дереве.
3.  Нажмите «⚡ Full Auto» для выполнения полного цикла на странице (Детект ➔ OCR
    ➔ Перевод ➔ Клин ➔ Экспорт).
4.  Либо для всей главы: нажмите «Translate Chapter», чтобы выполнить пакетный
    OCR на GPU и перевести всю главу за 1 запрос к Gemini.
5.  Перейдите в режим «Typeset ON»:
      - Кликайте по баблам для назначения персонажей (Speaker).
      - Перетаскивайте текст мышью (Drag&Drop) или масштабируйте рамки прямо на
        скане.
      - Меняйте кегль (A- / Auto / A+), жирность, курсив и шрифт в панели
        справа.
6.  Нажмите «Export Page» (страница моментально запечется в папку translated/).
7.  Нажмите «Folder», чтобы открыть готовую главу в Проводнике Windows.
